# 스케줄 시간 선택 설계 회고

## 날짜: 2026-08-03

## 배경
스케줄 시간 선택 기능을 개선하면서 다양한 시간-분 조합 지원에 대한 논의가 있음.

## 논의 사항

### 1. 초안: 시간 다중 선택 + 단일 분
- 시간: 0~23시 토글 버튼 (다중 선택)
- 분: 0, 10, 15, 30, 45 (단일 선택)
- 문제: 9시 20분, 15시 40분 처럼 각 시간마다 다른 분 설정 불가

### 2. 개선안: 시간-분 쌍 다중 등록
- `{ hour: 9, minute: 20 }`, `{ hour: 15, minute: 40 }` 형태로 등록
- 장점: 완전한 유연성
- 단점: 백엔드 cron 처리 복잡도 증가

### 3. cron 표현력 제약
```
# 이건 4개 다 실행됨 (의도한 2개가 아님)
20,40 9,15 * * *

# 각 시간-분은 별도 cron 필요
20 9 * * *
40 15 * * *
```

## 결론
- 성능 문제는 없으나 백엔드 변경 필요
- 기획 특색을 위해 시간-분 쌍 방식으로 개선 검토
- 기존 방식(다중 시간 + 단일 분)도 유지하여 선택지 제공

## 적용된 변경사항

### 프론트엔드 (Schedule.tsx)
- `hour: number` → `selectedHours: number[]` 변경
- 시간 선택: 24개 토글 버튼 → 오전/오후 2줄 배치
- 분 선택: 5개 → 12개 (5분 단위) 확대
- 미리보기: "오전 9시, 오후 1시 30분" 형태

### Viewer UI 개선
- 행 번호(#) 추가
- 사이트 파스텔 배지 (사람인-파랑, 잡코리아-초록, 원티드-빨강, 리멤버-보라)
- 행 클릭 시 URL 새 창 열기
- 스마트 페이지네이션 (7페이지 윈도우)
- 컬럼 너비 검색 결과와 동일

- 특색 있는 기능은 복잡도를 감수할 가치가 있음
