### 2. Fat JAR 전환 (bootRun → java -jar)
- **변경 전**: `gradlew :modules:auth:backend:bootRun` → Java 12개 프로세스, 3.1GB
- **변경 후**: `java -jar builds/sh-platform-auth.jar` → Java 4~6개 프로세스, ~1.5GB
- **효과**: 프로세스 67% 감소, 메모리 52% 절감, 시작 시간 6배 빠름

**변경 파일:**
- `modules/*/backend/build.gradle.kts`: `archiveBaseName` 설정 (모듈별 고유 JAR명)
- `systemd/*.service`: ExecStart를 `java -jar`로 변경 (-Xmx384m -Xms128m)
- `.github/workflows/deploy-backend.yml`: bootJar 빌드 + builds/ 복사 + systemd 배포

**systemd 서비스 구조 (변경 후):**
```
sh-platform-auth.service
  └─ /usr/bin/java -Xmx384m -jar builds/sh-platform-auth.jar
```

**systemd 서비스 구조 (변경 전):**
```
sh-platform-auth.service
  └─ gradlew java (Wrapper)
       └─ GradleDaemon java
            └─ Spring Boot App java
```

## 참고사항
- 4개 서비스 동시 시작 시 메모리 부족으로 auth/scraper 실패 → 순차 시작 필요

- 서버 `builds/` 디렉토리에 fat JAR 저장 (git에는 `.gitkeep`만)
