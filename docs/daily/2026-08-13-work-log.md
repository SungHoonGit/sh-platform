### 1. 웹 푸쉬 알림 버그 수정 (3건)

#### 1-1. Notification 생성자 파라미터 순서 오류 (치명적)
- **증상**: 모든 구독에서 `Invalid point encoding 0x4d` 에러 발생
- **원인**: `nl.martijndwars.webpush.Notification` 생성자 순서가 `(endpoint, p256dh, auth, payload)` 인데, `(endpoint, auth, p256dh, payload)` 로 호출
- **결과**: auth 키(16바이트)가 p256dh 공개키(65바이트 EC 포인트)로 파싱되면서 실패
- **수정**: `WebPushService.java:72-76` — 파라미터 순서 변경
- **교훈**: 라이브러리 API 문서의 파라미터 순서를 반드시 확인할 것

#### 1-2. DELETE 엔드포인트 @RequestBody 호환성 문제
- **증상**: `DELETE /api/v1/push/unsubscribe` → 500 Internal Server Error
- **원인**: Spring Boot에서 DELETE + `@RequestBody` 조합이 일부 프록시/클라이언트에서 불안정
- **수정**: `@RequestBody Map<String, String>` → `@RequestParam String endpoint` 로 변경
- **프론트엔드**: Request Body → Query Parameter 방식으로 변경

#### 1-3. 푸쉬 알림 설정 안내 툴팁 추가
- 푸쉬 알림 체크박스 옆 `?` 아이콘에 마우스 올리면 설정 안내 표시
- 안내 내용: 브라우저 알림 권한, Windows 알림 설정, 브라우저 항상 켜져 있어야 함
