## 신규로 알게된 것 (2026-08-20)
- **Windows에서 Docker = WSL2 필수**: 컨테이너는 Linux 프로세스라 WSL2(경량 VM) 위에서 실행. OS 무관 동일 환경 보장이 핵심 가치
- **WSL2 가상화 오류**: `wsl --install` 후 "가상화가 활성화되지 않음" → 관리자 PowerShell로 `dism /enable-feature:VirtualMachinePlatform` + BIOS VT-x(ThinkPad: Config→CPU) 필요
- **Docker 명령 PATH**: 설치 직후 셸에 미반영 → `C:\Program Files\Docker\Docker\resources\bin` 추가 필요
- **MySQL/MariaDB 포트 충돌**: Windows에 기존 `mysqld`가 3306 점유 가능 → Docker 컨테이너는 호스트 매핑 3307 사용 (내부는 3306)
- **localhost vs 127.0.0.1**: Windows JDBC에서 `localhost`는 IPv6(::1)로 해석되어 계정 매칭 실패 가능 → `127.0.0.1` 명시가 안전
- **Docker 공유 방식**: 이미지는 git에 안 올리고, git에는 `docker-compose.yml` 설정만. 각 PC가 Docker Hub에서 동일 이미지 자동 다운로드
- **K8s 도입 시점**: 이중화 라우팅은 systemd+nginx로 충분. 서버 3대+·서비스 10개+·자동 스케일링 필요 시에만 K8s 검토
