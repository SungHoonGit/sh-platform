```bash
# 서버에서 (사용자가 직접 실행 — AI는 SSH 불가)
curl -s http://localhost:8082/health
TOKEN="..."  # 로그인 API로 발급: curl -s -X POST http://localhost:8080/api/v1/auth/login -H "Content-Type: application/json" -d '{"email":"...","password":"..."}'
curl -s http://localhost:8082/api/v1/careers -H "Authorization: Bearer $TOKEN"
```

## 두 번째: Phase 3 나머지 6개 도메인

**`CareerServiceImpl`을 템플릿으로 복제**하면 된다. 패턴 동일:

| 도메인 | 테이블 | 특이사항 |
|--------|--------|----------|
| education | resume_educations | school/major/degree/status/date 2개 |
| skill | resume_skills | name/level/category, updated_at 없음 |
| certificate | resume_certificates | name/issuer/acquired_at, updated_at 없음 |
| project | resume_projects | name/role/tech_stack/link_url/description |
| introduction | resume_introductions | title/content(TEXT NOT NULL) |
| portfolio-item | resume_portfolio_items | item_type(FILE/LINK), Phase 5에 파일업로드 추가 예정 — 지금은 LINK만 |

각 도메인당 생성 파일 (career 예시 → 이름만 치환):
```
api/{Domain}Controller.java            (/api/v1/{plural}, @Tag/@Operation 필수)
api/dto/{Domain}Request.java           (record + validation)
api/dto/{Domain}Response.java          (record)
domain/{Domain}Service.java            (인터페이스 + Javadoc 필수)
domain/{Domain}ServiceImpl.java        (getOwnedCareer 소유자 검증 포함)
infrastructure/entity/Resume{Domain}Entity.java   (정적 팩토리 create(userId))
infrastructure/repository/Resume{Domain}Repository.java  (findByUserIdOrderByDisplayOrderAscIdAsc)
test/.../domain/{Domain}ServiceImplTest.java      (CRUD + NOT_FOUND + FORBIDDEN)
```

### 준수 규칙 (AGENTS.md 상세)
- 레이어: api → domain → infrastructure (역방향 import 금지; Response record는 infrastructure를 import하지 않게 Impl에서 필드 매핑)
- 엔티티 생성자 protected → `create(userId)` 팩토리 사용
- 커밋 메시지: `$env:TEMP\opencode\commit-msg.txt`에 쓰고 `git commit -F` (**write와 bash 병렬 실행 금지 — 레이스로 옛 메시지 적용 사례 있음**)
- 검증: `./gradlew :modules:resume:backend:test` 통과 후 커밋
