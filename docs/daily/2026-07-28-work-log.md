## 실시간 검색 API 배포 디버깅 완료

### 문제
실시간 검색 API (`POST /search`)가 404 에러 — Swagger에 엔드포인트 미등록

### 근본 원인 1: CI/CD가 스크래퍼 모듈을 배포하지 않음
- `deploy-backend.yml`은 `:sh-platform-auth:build`만 실행 (구 모노리포 기준)
- `paths` 트리거도 `sh-platform-auth/**`만 감시
- **수정**: 전체 모듈 빌드 및 배포로 변경 + `.github/workflows/` paths 추가

### 근본 원인 2: 서버의 JAR 경로 불일치
- Systemd 서비스: `/home/ubuntu/sh-platform/builds/sh-platform-scraper.jar`
- Gradle 빌드 출력: `modules/scraper/backend/build/libs/sh-platform-scraper-0.0.1-SNAPSHOT.jar`
- **수정**: deploy-backend.yml에 `cp` 명령어로 JAR 복사 단계 추가

### 근본 원인 3: DB 테이블 누락
- `SiteSearchMapping` 엔티티의 `site_search_mapping` 테이블이 서버 DB에 없음
- `schema-validation: missing table [site_search_mapping]` 에러로 애플리케이션 시작 실패
- **수정**: `mysql scraper_platform < docs/scraper/ddl-site-search-mapping.sql` 실행

### 근본 원인 4: GitLab CI 테스트 실패
- 테스트 13개 실패 (SearchServiceTest 4 + SiteSearchMapperTest 9)
- **원인**: SearchService가 CompletableFuture 내부에서 예외를 삼켜 failedSites 미동작
- **원인**: SiteSearchMapperTest에 ObjectMapper @Spy 누락
- **원인**: SearchServiceTest에 불필요한 SiteSearchMapper mock → strict stubbing 충돌
- **수정**: SearchService 예외 전파 방식 변경, ObjectMapper @Spy 추가, 불필요 mock 제거
