## 2. SSO 로그인 가드 + 로그인 상태 헤더 복원 — 커밋 acd5c86

### 문제 3건
1. **대시보드 스크래퍼 카드 이동 안 됨**: `navigate("/platform/scraper")` → React Router 리다이렉트(`/scraper/`)는
   같은 탭 client-side 전환이라 스크래퍼 SPA(별도 서빙)로 넘어가지 못함 → 빈 화면
2. **직접 URL 접근 시 SSO 미통과**: `https://sunghoonyk.duckdns.org/scraper/`를 바로 접근 가능 (로그인 게이트 없음)
3. **스크래퍼 우측 로그인 상태 사라짐**: 커밋 `e7c8511`(키워드 alias)에서 `common/frontend`가 통째로 삭제되며
   CommonHeader(사용자 정보 + 로그아웃)·useAuth·AuthGuard가 함께 삭제됨

### 해결
| 파일 | 변경 |
|------|------|
| `platform/frontend/src/pages/Dashboard.tsx` | 스크래퍼 카드 `window.open("/scraper/", "_blank")` 새 탭 |
| `platform/frontend/src/App.tsx` | `/platform/scraper/*` → `RedirectTo` 컴포넌트(`window.location.replace("/scraper/")`) 전체 페이지 리다이렉트 |
| `modules/scraper/frontend/src/components/AuthGuard.tsx` | (신규) 토큰 유효성 검증 → 미인증 시 `/?redirect=/scraper/` 로그인으로 이동 (SSO) |
| `modules/scraper/frontend/src/hooks/useAuth.ts` | (신규 복원) 토큰 → `/api/v1/auth/me` 프로필 조회 |
| `modules/scraper/frontend/src/api/auth.ts` | (신규 복원) fetchProfile / logout API |
| `modules/scraper/frontend/src/components/CommonHeader.tsx` | (신규 복원) 상단 헤더 우측: 사용자 아바타+이름 / 로그아웃 버튼 / 로그인 링크 |
| `modules/scraper/frontend/src/components/Layout.tsx` | CommonHeader(상단) + 스크래퍼 서브네비(통합검색/스케줄등록/뷰어) |
| `modules/scraper/frontend/src/App.tsx` | `<AuthGuard>`로 래핑 |
| `modules/auth/frontend/src/pages/Login.tsx` | `?redirect=` 파라미터 지원 (로그인 후 원래 페이지로 복귀) |

### 동작
- `/scraper/` 직접 접근 → AuthGuard가 토큰 확인 → 없으면 로그인 페이지(`/?redirect=/scraper/`)로 이동
- 로그인 성공 → `redirect` 파라미터 위치로 복귀 (`/scraper/`)
- 로그인 상태: 상단 헤더 우측에 사용자 이름 + 로그아웃 표시
- SSO는 UI 레벨 게이트 (스크래퍼 API 자체는 공개, 추후 백엔드 JWT 검증 고려)

### 검증
- scraper / platform / auth 프론트 모두 빌드 성공

### 참고
- OAuth2(카카오/네이버 등)는 `/auth/callback` 페이지가 auth 프론트에 없어 동작 확인 필요 (별도 이슈)
