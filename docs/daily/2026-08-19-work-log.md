## 오늘 완료된 작업

### 1. Promtail `service` 라벨 오류 수정 (relabel glob 함정) ✅
- **증상**: Loki `service` 라벨 값이 `["*"]`만 조회됨 → Grafana 변수 드롭다운이 비어 보임
- **원인**: glob 경로에 relabel 정규식(`.*/logs/([^/]+)/.*\.log`) 적용 시 파일명이 아니라 **glob 패턴(`logs/*/*.log`)의 `*`를 캡처** → 모든 스트림 `service="*"`
- **해결**: relabel 정규식 제거 → **서비스별 static_configs 분리 + 정적 `service` 라벨** (auth/scraper/resume/portfolio 4개 job, `job: spring-boot` 공통 유지)
- **검증**: 서비스 재시작 후 Loki에 `service=auth-platform` 스트림 확인. 라벨 값 `["*", "auth-platform", "scraper-platform"]` → 새 스트림 정상 수집. `*`는 옛 스트림 데이터 (새로 안 쌓임)

### 2. Spring Boot Log 대시보드 생성 (Loki) ✅
- **서비스 변수**: `service` (Loki, Label values, Label=`service`, Stream selector=`{job="spring-boot"}`) → 상단 드롭다운
  - **함정**: Label values 모드에서 `label_values(...)` 함수를 Stream selector에 넣으면 0개 — 스트림만 입력해야 함
- **패널 1**: 실시간 로그 목록 — `{job="spring-boot", service=~"$service"}` → **Logs**
- **패널 2**: 서비스별 로그 수 — `sum by (service) (count_over_time(...[5m]))` → **Bar chart**
- **패널 3**: ERROR 로그 수 — `sum by (service) (count_over_time(... |= "ERROR" [5m]))` → **Stat**
- **패널 4**: 로그 수 추이 — `sum(rate({job="spring-boot"}[5m]))` → **Time series**
- **학습**: 패널 하나 = 쿼리 하나. Logs 패널에 메트릭 쿼리를 섞으면 빈 화면. 빈 화면 시 시간 범위(Last 15 minutes) 먼저 확인

## 신규로 알게된 것 (2026-08-19)
- **Promtail relabel glob 함정**: 정규식은 대상 파일 경로가 아니라 **glob 패턴**에 적용될 수 있음 → `logs/*/*.log`에서 `*` 캡처. 서비스 구분은 **static_configs 정적 라벨**이 정규식보다 안전
- **Grafana 변수 (Label values 모드)**: `Label`엔 가져올 라벨명(`service`), `Stream selector`엔 **스트림만**(`{job="spring-boot"}`). `label_values()` 함수는 Query(LogQL) 모드용
- **Grafana 패널**: 하나의 패널 = 하나의 쿼리. Logs 시각화에는 로그 쿼리만, 메트릭은 별도 패널
- **Loki 라벨 값은 실제 푸시된 데이터 기준**: 새 라벨로는 새 로그가 쌓여야 스트림 생성 (서비스 재시작으로 로그 발생시켜 검증)
- **Promtail dry-run 권한**: ubuntu 계정으로 `promtail -dry-run` 시 positions.yaml permission denied — 설정 문법 자체는 통과, 무시 가능
