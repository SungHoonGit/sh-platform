## 이슈 및 해결
- Modern 템플릿은 문서 내부에 자체 `max-w-3xl mx-auto`를 내장 → 좌측 컬럼 내 중첩은 무해, 레이아웃 변화 없음.
- IntersectionObserver만으로는 짧은 마지막 섹션이 관찰 밴드에 닿지 않아 하이라이트가 멈추는 케이스 발생 →
  passive scroll 리스너로 문서 바닥 근처(8px)에서 마지막 항목으로 보정.
- resume frontend에는 lint 스크립트 없음 → 검증은 `npm run build`(tsc -b && vite build)로 수행, 통과.
- 라이브 번들 마커 검증 시 `/?redirect=`는 미니파이어가 템플릿 문자열을 분리(`` `${ki}?redirect=` ``)해 단일 문자열 검색 실패 →
  `?redirect=`·`location.pathname+`·auth의 `` startsWith(`//`) `` 게이트로 재검증.
- `/scraper/actuator/health`가 배포 직후 502 → 30초 후 200 (재기동 transient, 기존과 동일).
