## 이슈 및 해결
- **배포 DDL 실패: `ERROR 1060 Duplicate column name '1'` (docs/scraper/ddl-v7.sql:21)**
  - 원인: 멱등 시드의 유도 테이블 `(SELECT '사유', 1, 1) AS t`에서 두 개의 숫자 리터럴 `1`이
    자동 생성 컬럼 라벨 `1`로 충돌 → MySQL "Duplicate column name '1'" 발생. (CREATE TABLE은 성공,
    첫 INSERT에서 중단) — resume DDL은 서로 다른 문자열 리터럴이라 이 문제가 없었음.
  - 해결: 유도 테이블 내부에 명시적 컬럼 별칭 부여 `(SELECT '사유' AS name, 1 AS sort_order, 1 AS active) AS t`.
  - 재배포로 ddl-v7 재실행 (block_reasons 테이블은 이미 생성, 시드는 멱등이라 안전).
