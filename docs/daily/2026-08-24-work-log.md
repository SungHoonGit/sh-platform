## 이슈 및 해결

| 이슈 | 원인 | 해결 |
|------|------|------|
| ConflictingBeanDefinitionException (FileController) | common 모듈 @Component가 resume 컨텍스트에 함께 스캔됨(빈 이름=클래스 단순명) | resume 컨트롤러를 `ResumeFileController`로 리네임 — common과 같은 단순 클래스명 금지 |
| "스크랩에서 불러오기" 404 | nginx `location /scraper/ { proxy_pass .../; }` trailing slash → prefix rewrite됨 | 호출 경로를 `/scraper/api/v1/*` → `/scraper/*`로 수정. 모듈 간 API 호출 시 nginx rewrite 규칙 먼저 확인 |
| SaraminTemplate JSX 컴파일 에러 | `<Fragment>` 열고 `</React.Fragment>` 닫음 | 태그명 일치 |
| ApplicationController 중복 생성자 | @RequiredArgsConstructor와 명시 생성자 병존 | 명시 생성자 제거 |
